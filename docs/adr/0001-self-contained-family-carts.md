# 0001. 按家族发布自包含 Shader Cart

2026-10-29。依据 karma 在 Continue 项目中的确认开始实施。

每个着色器家族发布一张 Cart。Cart 内可包含多份 Shader 资源、变体与观感，并共享实现文件；不同 Cart 分别携带并维护完整代码与资产，不通过构件卡或挂载表引用对方内部实现。

固定上游快照、输入摘要与许可，构建时整理完整闭包。技术参数按 variant 自动提取，名称、说明、分组和选项等展示文字使用按语言标签映射的统一结构。用户参数 ID 与数值不随语言变化。

生成器输出可复现的 Cart 和审查报告。发布制品保持不可变；CartRelease 与资源版本分离。首个 GitHub/Cart Station 联动以明确的冒烟 prerelease 验证，不代表真实 GPU 或跨平台验收。

第一批最终验收覆盖 25 个精选。预设依赖语法与升级策略独立后定；任意 Shader 叠加不纳入本次联动切片。
